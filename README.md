# منصة إبان (Django)

منصة صوتية رقمية مهيأة بالكامل لذوي الإعاقة البصرية — يمكن للمستخدم تصفّح الموقع وتسجيل الدخول وطرح الأسئلة بصوته فقط دون استخدام اليد.

تحتوي على:
- صفحات: الرئيسية، الخدمات، من نحن، تواصل، قاموس المصطلحات (+ لوحة التحكم والدخول/التسجيل)
- نظام أدوار (Role):
  - **مستفيد من ذوي الإعاقة البصرية**: يرسل استفسارًا نصيًا أو صوتيًا ويتنقل بالأوامر الصوتية
  - **أخصائي مكتبة**: يحوّل الصوت إلى نص ثم يكتب الإجابة
- تنقّل صوتي عالمي عبر زر الميكروفون 🎙️ أو اختصار Alt+V
- تسجيل دخول صوتي بالكامل
- قراءة صوتية للنصوص (TTS) وإملاء صوتي (STT)
- هوية لونية عالية التباين: ❤️ أحمر، 💙 أزرق، 🤲 ذهبي، 🤍 أبيض
- خط IBM Plex Sans Arabic من Google Fonts

## تشغيل المشروع (محليًا)

> المتطلبات: Python 3.10+ (يفضل 3.11) و pip

```bash
cd taibah_voice_platform
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser

python manage.py runserver
```

افتح:
- الصفحة الرئيسية: `http://127.0.0.1:8000/`
- لوحة التحكم: `http://127.0.0.1:8000/service/dashboard/`
- لوحة المدير (Admin): `http://127.0.0.1:8000/admin/`
